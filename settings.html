Gemini 3.5 Flash-Lite connection

The API key is optional. Without it, a local Python ranker continues to recommend songs.

Get a key
The key is sent only to your Mousike server for Gemini requests. Optional Gemini uses a compact music-taste summary. A key kept on this device can be read by scripts or extensions with access to this origin.

Adaptive recommendations

No key: semantic genre/mood matching, artist balancing and song-identity deduplication. With Gemini: AI-assisted curation under the same no-repeat safeguards.
