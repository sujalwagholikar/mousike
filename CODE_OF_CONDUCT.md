# Community code of conduct

Project owner and maintainer: **Sujal Wagholikar**.

## Expectations

Communicate respectfully and focus criticism on code, evidence and behavior. Welcome questions, constructive disagreement and contributors with different experience levels. Respect privacy, accessibility needs, attribution and software-license obligations.

Harassment, threats, hateful conduct, personal attacks, doxxing, impersonation, repeated unwanted contact, sharing private credentials and deliberate disruption are not acceptable in project issues, pull requests, discussions or project-directed interactions. Do not use an unrelated support thread to expose a security vulnerability or someone's personal data.

## Reporting

Contact the maintainer through a suitable private channel if one has been provided. If no private channel is published, use the maintainer's public profile to request one without posting names, sensitive evidence or the details of a confidential complaint. Security vulnerabilities should follow SECURITY.md.

Provide the location and time of the conduct, a concise description and the action you are requesting. Share only evidence you may lawfully provide. Confidentiality will be handled with care, but this document does not guarantee absolute secrecy or confidentiality of third-party systems.

## Maintainer process

Review available evidence fairly, consider context, minimize unnecessary disclosure and state any action clearly. Responses may include requesting a correction, warning, moderating a thread, temporarily limiting participation or removing participation for serious/repeated behavior. A person may request reconsideration with new context through an appropriate channel.

The policy applies to project-controlled spaces and project-related interactions. It does not create employment obligations, a paid moderation service, a guaranteed response deadline or authority over unrelated third-party communities. If a report concerns the maintainer, independent review is recommended where a suitable reviewer is available; no additional reviewer is represented as already appointed.
