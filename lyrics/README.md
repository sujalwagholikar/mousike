Lyrics are optional. No lyrics are scraped, generated, or distributed in this app.

Use **Now Playing → Lyrics → Import .lrc** to keep lyrics you have permission to
use in your browser. Clicking a lyric line seeks to that timestamp.

For installation-supplied licensed sidecars, save the LRC here with a filename
printed by:

```bash
python -c "from lyrics import lyrics_key; print(lyrics_key('Song title', 'Artist') + '.lrc')"
```

Keep any license and attribution alongside the sidecar. Do not place API keys or
private files in this directory. The lyrics API reads only the matching LRC file.
