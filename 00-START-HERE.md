**Project owner and maintainer: Sujal Wagholikar**  
**Brand: Mousiké · Sound In motion**  
Prepared: 27 October 2026 · Repository: https://github.com/sujalwagholikar/mousike

This ZIP contains Markdown documentation only. It does not contain application code, APKs, installers, credentials or signing keys. It documents the supplied Android project, Windows adaptation and showcase website; it does not change their behavior or licensing retrospectively.

## Install these documents step by step

1. Back up the repository's existing policy documents and compare any local changes.
2. Copy LICENSE.md, LICENSING.md, COPYRIGHT.md, SECURITY.md, PRIVACY.md, TERMS.md, THIRD_PARTY_NOTICES.md, CONTRIBUTING.md, CODE_OF_CONDUCT.md and SUPPORT.md into the repository root.
3. Keep the app's existing README.md. Move this index and the SETUP, RELEASE and ARCHITECTURE guides into a `docs/project/` directory if desired, updating relative links after moving.
4. Keep existing platform LICENSE files and every original dependency/font license. LICENSE.md contains an unchanged copy of the GPLv3 text already included in the project. Do not replace an existing LICENSE with a contradictory license.
5. Review PRIVACY.md against the exact build you distribute and the hosting provider you choose. Record additional endpoints, logging or SDKs before releasing them.
6. Enable private vulnerability reporting in GitHub repository settings. SECURITY.md does not enable this feature by itself.
7. Add links to Privacy, Security, Terms, Copyright and Source in the website footer and installed app's About page. This pack does not automatically add those links.
8. Follow RELEASE.md to publish binaries with matching source, checksums and notices. A link to an upstream homepage alone is not a substitute for satisfying applicable source-distribution obligations.
9. Commit the Markdown documents after review. Do not commit real API keys, production signing keys, user exports or logs.
